# Dumpster Diving Simulator

Playable Roblox MVP with:
- 6 dumpster tiers
- random trash loot
- rare egg drops
- egg hatching
- collectible pets
- pet luck/sell bonuses
- trash selling
- automatic tier unlocks
- DataStore saving
- auto-generated demo map

## Play loop
1. Walk to a dumpster.
2. Hold E to dive.
3. Find trash or a rare egg.
4. Sell trash on the green SELL TRASH pad.
5. Better dumpsters unlock as your cash increases.
6. Hatch eggs from the Eggs button.
7. Pets automatically equip up to 3 and increase sell value/luck.

## Import with Rojo
1. Install Rojo and the Roblox Studio Rojo plugin.
2. Run `rojo serve` in this folder.
3. Connect from Roblox Studio.
4. Sync and press Play.

To test DataStore saving in Studio, enable:
Game Settings > Security > Studio Access to API Services.
